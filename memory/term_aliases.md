# Term Aliases

本页维护 ResearchWiki 的术语同义词映射，防止重复建页。领域术语应根据 `memory/project_profile.md` 逐步补充。

## Record Format

```markdown
## Main Term

- Aliases:
- Recommended page:
- Recommended tag:
- Note:
- Status: active / 待确认
```

## General Terms

### Literature Review

- Aliases: 综述、文献综述、survey、review paper、related work
- Recommended page: `[[wiki/reviews/Literature Review Notes]]`
- Recommended tag: `review`
- Note: 用于综述写作、研究现状整理和 related work 输出。
- Status: active

### Research Gap

- Aliases: gap、研究空白、研究不足、open problem、open question
- Recommended page: `[[synthesis/open-questions]]`
- Recommended tag: `gap`
- Note: 具体 gap 应创建到 `wiki/gaps/`，跨论文开放问题汇总到 `synthesis/open-questions.md`。
- Status: active

### Claim

- Aliases: 论断、关键判断、evidence-backed statement、finding
- Recommended page: `wiki/claims/`
- Recommended tag: `claim`
- Note: 可被综述复用、可追溯到论文证据的判断应沉淀为 claim。
- Status: active
