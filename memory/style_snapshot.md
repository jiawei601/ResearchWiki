# Style Snapshot

本页只记录默认输出风格和写作偏好。具体研究领域和用途写入 `memory/project_profile.md`。

## 默认语言

- 中文为主。
- 必要时保留英文术语，特别是 agent、template、claim、gap、review、synthesis 等项目结构词。

## 默认表达风格

- 简洁、清晰、可执行。
- 优先说明结论，再说明原因和下一步。
- 学术内容强调证据、来源和不确定性。
- 不使用空泛表达；如果证据不足，标注“待确认”“待核查”或 `AI 推断`。

## 文件维护风格

- `AGENTS.md` 保持轻量。
- 详细规则放入 `memory/`、`agents/`、`templates/` 和 `synthesis/`。
- 不把具体专业写死到通用规则中。
- 不导入论文时，不创建具体 paper/topic/method/claim/gap 页面。

## 汇报偏好

- 汇报创建了哪些文件、更新了哪些文件。
- 说明验证结果。
- 给出下一步建议，但不自动扩展任务范围。
