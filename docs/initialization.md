# Initialization Guide

Use this guide when turning the template into your own paper knowledge base.

1. Fill `memory/project_profile.md`.
2. Add initial tags in `memory/tag_taxonomy.md`.
3. Add term aliases in `memory/term_aliases.md`.
4. Add papers to `raw/papers/` or use Zotero import.
5. Ingest one paper first.
6. Run `agents/lint_agent.md`.
7. Only then import more papers.
